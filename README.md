# أرشيف فيديوهات Facebook

مستودع عام لحفظ مقاطع MP4 التي تملك حق إعادة نشرها، مع إجراء GitHub Actions لتنزيل المقاطع من روابط Facebook عبر Floader.

## التشغيل

1. افتح تبويب **Actions** ثم إجراء **Download Facebook videos**.
2. اختر **Run workflow**.
3. الصق روابط Facebook أو `fb.watch` مفصولة بفاصلة `,` (ويمكن أيضًا فصلها بمسافات أو وضع كل رابط في سطر).
4. شغّل الإجراء. يستخرج رابط HD، ويحفظ الفيديو في `videos/` باسم معرّف المشاركة، ثم ينشئ commit ويرفعه إلى الفرع الافتراضي.

الملفات الموجودة حاليًا في `videos/` هي المقاطع التي جُمعت عند إنشاء المستودع.

## حدود وملاحظات

- يقبل الإجراء حتى 30 رابطًا في كل تشغيل، ويقبل روابط HTTPS من Facebook أو `fb.watch` فقط.
- يتخطى الروابط غير المدعومة أو التي لا يعيد Floader لها جودة HD، ويُكمل رفع بقية الملفات الناجحة؛ إذا لم ينجح أي تنزيل فسيفشل التشغيل.
- تُرفض الملفات الأكبر من 95 MiB لتفادي حد GitHub البالغ 100 MiB للملف الواحد.
- روابط Facebook المباشرة مؤقتة؛ لذلك يعيد الإجراء استخراج رابط HD عند كل تشغيل.
- يعتمد التنزيل على توفر خدمة Floader واستقرار واجهتها.
- المستودع عام، وأي ملف MP4 يُرفع إليه يصبح متاحًا للعامة. لا تستخدمه إلا للمقاطع التي تملك حق نشرها.
